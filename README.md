# 🏦 Python Banking System (CLI Based)

A simple yet robust **Command-Line Banking Application** built using Python. This project demonstrates core programming concepts like:

* Input validation
* Error handling
* Loops & conditionals
* Data structures (dictionary)
* Modular function design

## 🚀 Features

✅ Create new bank account
✅ Secure 4-digit PIN authentication
✅ Deposit money
✅ Withdraw money (with balance check)
✅ Check account balance
✅ Unique account number generation
✅ Input validation & exception handling


## 🛠️ Tech Stack

* **Language:** Python 🐍
* **Concepts Used:**

  * Functions
  * Loops (`while`)
  * Conditional Statements (`if-else`)
  * Exception Handling (`try-except`)
  * Dictionaries

## 📂 Project Structure

banking-system/
│── main.py        # Main application file
│── README.md      # Project documentation


## ⚙️ How It Works

1. User selects:

   * New User
   * Existing User

2. New User:

   * Enters name, deposit, and PIN
   * System generates unique account number

3. Existing User:

   * Logs in using account number + PIN

4. User can:

   * Deposit 💰
   * Withdraw 💸
   * Check Balance 📊
